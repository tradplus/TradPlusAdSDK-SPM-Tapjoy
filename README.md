# TradPlus Tapjoy Adapter Swift Package

Swift Package Manager support for the TradPlus Tapjoy adapter (15.13.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Tapjoy.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Tapjoy.git", exact: "15.13.0")
```

Third-party dependency: Tapjoy SDK `13.4.0`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.13.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
